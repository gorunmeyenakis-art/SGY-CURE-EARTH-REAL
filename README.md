# 🛰️ SGY CURE-EARTH (KIZILELMA) - REAL TIME AUTOMATION
**Baş Mimar:** Sadık Güray Yıldız (SGY)

Bu proje; Termux edge computing altyapısı, Aeron IPC ultra-düşük gecikmeli mesajlaşma motoru ve PLC/Modbus haberleşme protokollerini kullanarak yazılımı fiziksel saha otomasyonu ve endüstriyel üretim hatlarıyla buluşturan otonom kontrol mimarisidir.

## 🚀 İçerik
- `sgy_master_v7.py`: Ana omurga ve modül kontrolcüsü
- `simule_tetikleyici.py`: Modbus TCP saha simülasyon ve aktüatör tetikleyici
